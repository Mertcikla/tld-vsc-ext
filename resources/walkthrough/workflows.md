## Authoring Workflows

| Workflow | Command | When to use |
|---|---|---|
| **Manual** | `tld serve` | Edit diagrams freely in the browser |
| **Analyze** | `tld index --map` | One-time scan for code↔diagram links |
| **Watch** | `tld index --watch --map` | Continuous sync while you code |
